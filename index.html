6.8.1

Clustering as Structure Discovery

Clustering seeks to uncover latent structure in data when no class labels are available. Unlike supervised learning, there is no single "correct" answer; instead, clustering algorithms impose inductive biases about what constitutes meaningful structure.

In practice, clustering answers fundamental questions:

  • Are there natural groupings in the data?
  • At what level of granularity do these groupings emerge?
  • How stable are these structures under noise and sampling variation?
Key Insight

Because clustering is ill-posed, the choice of algorithm implicitly defines the notion of similarity and structure being discovered. Different algorithms will reveal different aspects of your data.

6.8.2

Objective Functions and Implicit Assumptions

Every clustering method optimizes (explicitly or implicitly) an objective function. Understanding these objectives reveals the assumptions baked into each algorithm.

k-Means Objective

k-means minimizes within-cluster squared Euclidean distance:

k-Means Objective Function J = Σₖ Σᵢ∈Cₖ ‖xᵢ − μₖ‖²

This implies strong assumptions:

Convex Clusters

Clusters are assumed to be roughly spherical and convex in shape.

Isotropic Variance

All dimensions contribute equally; no directional bias.

Meaningful Distance

Euclidean distance in feature space must be semantically meaningful.

Warning

These assumptions often fail in high-dimensional, noisy, or correlated data—motivating alternative formulations like GMMs.

6.8.3

Hierarchical Clustering in Depth

Hierarchical clustering does not optimize a single global objective. Instead, it constructs a nested sequence of partitions, revealing structure at multiple resolutions.

Linkage Criteria

The choice of linkage defines cluster proximity:

Single Linkage

d(A,B) = min d(x,y)

Tends to produce chaining effects. Best for elongated clusters.

Complete Linkage

d(A,B) = max d(x,y)

Produces compact clusters but is sensitive to outliers.

Average Linkage

d(A,B) = avg d(x,y)

Balances compactness and robustness. Often preferred.

Algorithmic Properties

  • Time complexity: typically O(n² log n)
  • Memory intensive: stores full distance matrix
  • Deterministic: once distance metric is fixed
6.8.4

Probabilistic Clustering and Mixture Models

Probabilistic clustering assumes data is generated by a mixture of latent distributions. This soft assignment approach provides uncertainty quantification.

Gaussian Mixture Models (GMMs)

Each cluster k is parameterized by:

  • Mean μₖ — cluster center
  • Covariance Σₖ — cluster shape and orientation
  • Mixing coefficient πₖ — cluster weight
GMM Likelihood L = ∏ᵢ Σₖ πₖ · N(xᵢ | μₖ, Σₖ)

Expectation-Maximization (EM)

EM alternates between two steps until convergence:

EM Algorithm Steps INTERACTIVE
E
Expectation Step: Compute posterior cluster responsibilities P(k|xᵢ) for each point
M
Maximization Step: Update parameters (μ, Σ, π) to maximize expected log-likelihood
?
Convergence Check: If log-likelihood change < ε, stop; otherwise return to E-step
Soft vs Hard Assignment

Notice how points are colored by their probability of membership (soft assignment) rather than belonging entirely to one cluster. Points with mixed colors indicate uncertainty about cluster membership—a key advantage of probabilistic models over k-means.

Relationship to k-Means

k-means can be derived as a special case of GMMs with:

  • Equal, spherical covariances (Σ = σ²I)
  • Hard assignments (responsibilities → 0 or 1)
  • Identical mixing weights (πₖ = 1/K)
Key Insight

Probabilistic clustering strictly generalizes k-means, offering soft assignments and richer cluster shapes at the cost of computational complexity.

6.8.5

Model Selection and the Number of Clusters

Unlike supervised learning, clustering lacks labels for validation. Choosing k requires balancing fit against complexity.

Common Strategies

BIC / MDL Criteria

Penalize model complexity to prevent overfitting. Lower is better.

Stability Analysis

Run clustering multiple times; stable clusters are more reliable.

Domain Knowledge

Interpret clusters; do they make semantic sense?

Bayesian Information Criterion BIC = −2 log L + p · log n

Where p is the number of parameters and n is the sample size. This discourages overfitting by excessive cluster proliferation.

6.8.8

Computational Considerations

Algorithm choice is a trade-off between expressiveness, speed, and interpretability:

Method Time Complexity Scalability Interpretability Cluster Shape
k-Means O(nkT) Excellent Low Spherical
Hierarchical O(n² log n) Poor High Any
GMM (EM) O(nkT) Moderate Medium Elliptical

Where: n = instances, k = clusters, T = iterations

Clustering as Foundation

Clustering often serves as:

  • A preprocessing step for classification
  • A basis for semi-supervised learning
  • A tool for feature construction
Summary

Advanced clustering methods move beyond geometric partitioning to represent uncertainty, capture complex structure, and support principled model selection. Understanding their assumptions and limitations is essential when applying clustering to real-world data mining tasks.
